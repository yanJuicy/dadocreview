## 2026-04-27 퀴즈 결과

📌 **사용자 답변 및 피드백**

1. **답변:** `None` (정답! 🎉)
   - 파이썬의 `None`은 값이 없음을 명시적으로 나타내며, 스크래핑 실패 시 로직의 흐름을 제어하기 위한 아주 훌륭한 신호탄이 됩니다.
2. **답변:** `HTTPException` (정답! 🎉)
   - FastAPI에서 `raise HTTPException`을 사용하면 프레임워크가 이를 낚아채서 브라우저에 예쁜 JSON 에러 응답을 대신 보내줍니다.
3. **답변:** `timeout=5` (정답! 🎉)
   - 외부 서버는 언제든 느려지거나 응답을 안 할 수 있습니다. `timeout` 설정은 우리 서비스의 생명줄과 같습니다.
4. **답변:** `예외 처리` (절반의 성공! 👍)
   - 넓은 의미에서는 예외 처리가 맞지만, 특히 함수 초반에 에러 조건을 미리 쳐내서 코드의 가독성을 높이는 이 기법의 이름은 **'Guard Clause (가드 절/보호 절)'** 혹은 **'Early Exit'** 패턴이라고 부릅니다.
5. **답변:** (미응답)
   - 정답은 **'Graceful Degradation (우아한 성능 저하)'**입니다. 외부 API가 고장 나도 앱이 뻗지 않고 "리뷰를 가져올 수 없습니다" 정도로만 표시하며 서비스를 유지하는 똑똑한 전략이죠.

> **워밍업 완료! 아주 훌륭한 정답률입니다. 특히 핵심 코드 설정(timeout, HTTPException)을 정확히 기억하고 계시네요.**

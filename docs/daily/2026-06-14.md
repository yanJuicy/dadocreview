## 1️⃣ 주요 구현 내용

### A. 즐겨찾기 섹션 HTML 구조 (`index.html`)
- `.favorites` 섹션 내부를 다음 구조로 완성:
  - `<h3>⭐ 즐겨찾기</h3>`: 섹션 타이틀
  - `.favorites-books`: 가로 스크롤 카드 목록 컨테이너
    - `.favorite-card` × 3개: mock 카드 (이후 JS로 동적 교체 예정)
  - `.favorites-empty`: 즐겨찾기가 없을 때 안내 문구 (`.favorites-books` **바깥**에 분리 배치)

> [!IMPORTANT]
> `.favorites-empty`는 `.favorites-books` 안이 아니라 **형제 요소(바깥)**로 배치해야 JS로 show/hide 제어가 쉽다.

### B. CSS 스타일링 (`index.css`)
- `.favorites`: `display: flex; flex-direction: column; flex-grow: 1; padding-bottom: 80px`
- `.favorites-books`: `display: flex; overflow-x: auto; flex-grow: 1; justify-content: flex-start`
- `.favorite-card`: `width: 100px; height: 200px; flex-shrink: 0`
- 표지 이미지: `width: 100%; height: 100%; border-radius: 8px`

### C. 화면 전체 높이 채우기 패턴 (`common.css`)
즐겨찾기 섹션이 남은 화면을 꽉 채우도록 3단계 설정:
```
1. .app-container → min-height: 100vh; display: flex; flex-direction: column;
2. main           → flex-grow: 1; display: flex; flex-direction: column;
3. .favorites     → flex-grow: 1;
```

### D. 모바일 가로 스크롤 패턴
카드가 모바일에서 찌그러지는 문제 해결:
- `.favorite-card`에 `flex-shrink: 0` 추가 → 크기 고정
- `.favorites-books`에 `overflow-x: auto` 추가 → 넘치면 스크롤
- `justify-content: center` → `flex-start`로 변경 → 첫 카드 잘림 버그 방지

## 2️⃣ 이번 세션에서 배운 핵심 개념

| 개념 | 핵심 내용 |
| :--- | :--- |
| `min-height: 100vh` | 내용 없어도 화면 전체 높이 보장. `flex-grow` 연쇄의 출발점 |
| `flex-grow: 1` | 부모의 남는 공간을 모두 차지하며 늘어남 |
| `flex-shrink: 0` | Flex 안에서 강제로 찌그러지지 않도록 크기 고정 |
| `overflow-x: auto` | 가로로 내용이 넘칠 때 스크롤 생성. `flex-shrink: 0`과 세트 |
| CSS 태그 선택자 | `main { }` 처럼 클래스 없이 태그 이름으로 바로 스타일 지정 가능 |
| `justify-content: flex-start` | 가로 스크롤 영역에서 `center` 대신 써야 첫 카드가 잘리지 않음 |

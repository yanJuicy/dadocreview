## 2️⃣ 트러블슈팅 (Troubleshooting)

### # Pandas Excel Parsing `KeyError`
- **현상:** `import_libraries.py` 실행 시 `KeyError: '도서관명'` 발생.
- **원인:** 엑셀 파일 상단에 저작권 안내 문구 등이 포함되어 있어, 판다스가 `header=6`으로 설정했을 때 잘못된 행(참여도서관 건수)을 헤더로 인식함.
- **해결:** `df.columns.tolist()`를 출력하여 실제 인식된 헤더를 확인하고, `header=7`로 값을 수정하여 정상적인 컬럼 맵핑 완료.
- **교훈:** 외부에서 가져온 Raw 데이터(Excel, CSV 등)를 파싱할 때는 반드시 헤더와 인덱스의 실제 구조를 `print`문 등으로 검증한 후 진행해야 함.
